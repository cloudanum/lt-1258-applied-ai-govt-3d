**Goal:** Verify one AI answer before trusting it..

**Why it matters:** Verify one AI answer before trusting it is a core AI-at-work habit; doing it in chat makes the reasoning visible and easy to correct.

**Assets:** Approved AI assistant + source..

## Run steps
1. Ask one factual question.
2. Verify against source.
3. Post verdict + source.

**Common mistake to name:** The common mistake is a long answer with no source or format; require one reason, one source, or one required field.

**If finished early:** If finished early, improve one answer by adding a constraint: audience, format, source limit, or refusal rule.
