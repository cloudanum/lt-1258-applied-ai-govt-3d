## Run steps
1. Ask answerable question.
2. Ask unanswerable question.
3. Add rule: quote or say not stated.

**Common mistake to name:** A common failure is asking only answerable questions; the unanswerable question is what proves grounding.

**If finished early:** If finished early, add a second grounding rule: require a quote and page/section reference for every claim.
