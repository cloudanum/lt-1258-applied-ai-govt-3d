Open `1258-DoNow-Master-Guide-Standalone.html` first. It links each Do Now to its asset pack under `do-now-assets/`.

Contents:
- `1258-DoNow-Master-Guide-Standalone.html` — searchable/linked master guide with activity↔solution links and relative asset-pack links.
